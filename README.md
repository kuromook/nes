# NES ゲーム開発プロジェクト

ファミコン (NES) 用ゲームを cc65 ツールチェーン (ca65 アセンブラ) で開発するプロジェクト。

横スクロールの2画面ワールドを動き回り、8枚のコインを集めるアクション。
順番どおり連続で取るほど得点が増える（コンボ）。トゲや動く敵に触れるとミス。
8枚すべて取るとゴール（金の星）が出現し、触れるとステージクリア。

**全5面構成**。面ごとに要素を積み増していく（面1=足場＋コイン → 面2=＋トゲ → 面3=＋敵
→ 面4=＋アイテム「2段ジャンプ」→ 面5=＋アイテム「リバース」）。5面クリアで1面へ戻り、
周回ごとに敵が速くなって無限に難化する。スコアは面をまたいで加算。右上に現在の面番号を表示。

**周回で配色が変わる**。1周目はデフォルト色、2周目以降で空・足場のレンガ・敵の体色が
変化する（夕暮れ→夜→毒の順、以降は最後の配色で固定）。難易度の上昇と見た目がリンクする。

**残機制**。初期5機で、ミスするたびに残機が1減りその面を最初からやり直す（スコア・面は保持）。
残機が0になると **GAME OVER**（画面停止）→ Start でニューゲーム（1面・5機・スコア0から）。
残機は上部中央にプレイヤーアイコン＋数字で表示。

## 開発環境

| 役割 | ツール | 状態 |
|------|--------|------|
| アセンブラ / リンカ | cc65 (ca65 / ld65) V2.18 | インストール済み |
| エミュレータ | FCEUX | `sudo apt install fceux` |
| ビルド | make | インストール済み |

## ディレクトリ構成

```
.
├── Makefile      ビルド定義
├── nes.cfg       ld65 リンカ設定 (NROM-256, mapper 0)
├── src/
│   └── main.s    メインソース (6502 アセンブリ)
├── images/       README 用スクリーンショット
├── work_log.md   開発ログ (進捗の詳細)
└── game.nes      ← ビルド生成物 (.gitignore 済み)
```

## 使い方

```bash
make        # game.nes をビルド
make run    # ビルドして FCEUX で起動
make clean  # 生成物を削除
```

## 操作

- 十字キー左右: 移動 / A ボタン: ジャンプ / Start: クリア表示中に押すと次の面へ
- 次に取るコイン（点滅）を順番に取ると得点アップ。連続で取るほどボーナス増（最大8枚で447点）
- 順番外のコインも取れるが、取るとコンボがリセット（その分の点は32に戻る）
- トゲ・敵に触れるとミスで残機-1、その面を最初からやり直し（スコア・面は保持）
- 残機が0になると GAME OVER。Start でニューゲーム（1面・5機・スコア0から）
- 8枚集めてゴール（金の星）に触れると面クリア → Start で次の面へ

## メモ

- ROM 構成は NROM-256 (PRG 32KB + CHR 8KB, mapper 0)、垂直ミラーで横スクロール。
- 実装済み: コントローラ入力 / スプライト移動 / 重力・ジャンプ / 背景ステージ / 足場の当たり判定 / 横スクロール(2画面) / コイン収集＋コンボ得点 / トゲ・敵＋ミス処理 / ゴール＋ステージクリア / アイテム(2段ジャンプ・リバース) / 全5面の段階的ステージ進行＋周回難化 / 残機制＋ゲームオーバー / 周回ごとの配色変更。詳細は `work_log.md`。
- 配色更新(`update_palette`)は変化フレームのみ・NMI 冒頭(vblank 内)で実行する。毎フレーム末尾で `$2006` を叩くと NMI が vblank を超えて背景スクロールが乱れる（点滅・位置ずれ）ため。
- 面構成は機能トグル方式: 背景(足場)は全面共通で、`stage` 変数に応じてトゲ/敵/アイテムの有無と種別を切替える（`main.s` の各 `check_*`/`draw_*`/`update_*` 冒頭のゲート）。
- このマシンの Mesa ハードウェアGLだと FCEUX が入力時にフリーズするため、`make run` は `LIBGL_ALWAYS_SOFTWARE=1` 付きで起動する。
